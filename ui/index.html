    How to connect YouTube
    1. Create a Google Cloud project and turn on YouTube Data API v3.
    2. Create an OAuth client of type Desktop and download its JSON.
    3. Press Connect and sign in with the Google account that owns the channel.

    How to connect a Facebook Page
    1. Create a Meta app and add the Facebook Login product.
    2. Request the pages_manage_posts permission for the Page you post to.
    3. Press Connect, sign in, and pick the Page.
